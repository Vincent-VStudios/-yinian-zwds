## 📖 项目介绍

### 这是什么？

**一念紫微斗数**是一款结合AI大语言模型与传统紫微斗数理论的深度命理解盘系统。它不等同于普通的排盘软件——它不仅能排出精确的12宫命盘，更能利用DeepSeek等AI模型，对命盘进行多维度、多层次的结构化解读，输出ChatGPT级别的深度阅读报告。

### 为什么做这个？

市面上紫微斗数App和网站不少，但普遍面临三个问题：

| 问题 | 传统方案 | 一念ZWDS |
|---|---|---|
| **解读深度** | 机械套用模板，千篇一律 | 四层Prompt架构，每位用户获得专属深度解读 |
| **门派视野** | 只懂单一流派 | 三合派+飞星派+占验派三派融合 |
| **国际化** | 只有中文 | 支持6种语言，英文深度解盘 |
| **可接入性** | 封闭App | Telegram Bot + Web + REST API 三端互通 |
| **AI能力** | 规则引擎老旧 | 最新的DeepSeek/Claude/GPT多模型驱动 |

### 谁在用？

- **C端用户**：通过Telegram Bot或Web页面输入生辰，获取AI深度解盘
- **B端开发者**：通过REST API获取排盘数据和AI解读，集成到自建系统
- **文化研究者**：作为紫微斗数知识的参考工具

## 🚀 快速开始

### 环境要求

- **Python:** 3.10 或更高版本
- **Node.js:** 18+（Web前端需要）
- **API Key:** DeepSeek API Key（建议，也可用Claude/GPT）

### 第一步：安装排盘引擎

```bash
pip install iztro-py==0.3.4
```

iztro-py是SylarLong开发的Python版紫微斗数排盘库，精确度经过社群验证。安装完后可以直接在Python中排盘。

### 第二步：快速排盘测试

```bash
python3 -c "
from zwds_calc import generate_astrolabe, format_astrolabe
r = generate_astrolabe('2000-8-16', 6, '男')
print(format_astrolabe(r))
"
```

成功输出示例：
```
📅 四柱：庚辰 甲申 丙午 甲午
🐲 生肖：龙　五行：土五局
🏠 命宮：命宫　身宮：命宫

⚡ 生年四化
  · 子女宫：太阳化禄
  · 财帛宫：武曲化权
  · 父母宫：太阴化科
  · 疾厄宫：天同化忌

📋 十二宮星盤
▪ 命宫(戊寅)：紫微(旺) 天府(庙) 〔天马〕
▪ 父母宫(己卯)：太阴(得)→科
...
```

### 第三步：配置API key（AI解盘需要）

在运行环境中设置DeepSeek API Key：

```bash
export DEEPSEEK_API_KEY="sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

或者在OpenClaw的 `~/.openclaw/openclaw.json` 中配置：

```json
{
  "models": {
    "providers": {
      "deepseek": {
        "apiKey": "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
      }
    }
  }
}
```

### 第四步：启动Web前端（可选）

```bash
cd web
npm install
npx next dev -p 3001
```

浏览器打开 `http://localhost:3001`，输入生辰即可查看星盘SVG彩图。

### 第五步：启动后端API（可选）

```bash
cd backend
python3 app.py
# API服务运行在 http://localhost:8008
```

/zwds 2000-8-16 6 男 --deep    ← 排盘+AI深度解盘

**`/reading`** — 四层AI深度解盘（最核心功能）

> ```

> 2. 12宫逐一解读

> 4. 特殊格局识别
> 5. 当前大限十年运
> 6. 来因宫+体用宫分析
> 7. 2026年流年运势（5维度）

### 核心设计决策

#### 1. 双轨排盘方案

| 方案 | 引擎 | 用于 | 优势 |
|---|---|---|---|
| 后端排盘 | iztro-py (Python) | Telegram Bot / API | 集成AI方便，计算可靠 |
| 前端排盘 | iztro (JS) | Web可视化 | 零后端依赖，实时渲染 |

两者计算结果一致，验证通过。

#### 2. 宫序映射（关键坑点）

iztro-py返回的12宫按**固定地支顺序**排列（寅=0, 卯=1...丑=11），但紫微斗数标准序是**从命宫开始逆时针**（命宫→父母宫→福德宫...）。

```python
# 核心映射代码
soul_iztro_idx = BRANCH_TO_INDEX[soul_branch]  # 命宫的地支索引
for i in range(12):
    raw_idx = (soul_iztro_idx + i) % 12        # 逆时针旋转
    zwds_palaces[i] = iztro_palaces[raw_idx]
```

错误的映射会导致解读完全错误。

#### 3. AI模型选型对比

| 因素 | DeepSeek | Claude | GPT |
|---|---|---|---|
| 国内直连 | ✅ 是 | ❌ 需代理 | ❌ 需代理 |
| 中文紫微斗数 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ |
| 成本 | 极低 | 较高 | 较高 |

**结论**：DeepSeek中文场景最优，国内直连零延迟。

#### 4. 大限算法

采用标准中州派：
- **阳男阴女**：顺行；**阴男阳女**：逆行
- **每宫10年**（固定，不分五行局）
- 从命宫开始，第1大限起运

## 🧠 AI深度解盘系统

### 四层Prompt架构（核心创新）

传统AI解盘的通病：给AI扔一堆原始数据让它自由发挥，输出的质量像抽奖。一念ZWDS的**四层架构**让AI的输出稳定、结构化、有深度。

#### Layer 1：基础层 — 十二宫详解

目的：让AI逐宫理解星曜布局

**输入结构**（以命宫为例）：
```
▪ 命宫（丙子）：紫微(平)
  辅星：无
  三方四正：迁移宫(贪狼利) · 财帛宫(武曲科天相) · 官禄宫(廉贞禄天府)

▪ 父母宫（丁丑）：【空宫——借对宫交友宫(太阴陷+地空劫)】
  辅星：天魁、陀罗
  三方四正：交友宫 · 疾厄宫 · 子女宫
```

每个宫位告诉AI：干支+主星+亮度+四化+辅星+三方四正+空宫借星

#### Layer 2：进阶层 — 四化+格局+宫位关系

目的：从宏观了解四化脉络和格局

```
生年四化：廉贞禄(官禄) | 破军权(福德) | 武曲科(财帛) | 太阳忌(子女)
格局识别：杀破狼 ✓ | 机月同梁 ✓ | 紫微朝垣 ✓
六亲关系：夫妻宫七杀→武曲科(财帛) → 配偶影响财运
```

告诉AI：四化分布→因果链→格局含义→宫位互动

#### Layer 3：高阶层 — 时间维度

目的：引入时间线

```
当前大限：官禄宫（42-51岁）廉贞化禄+天府庙旺
大限四化：官禄宫自化禄 → 资源流动快

  · 感情：桃花旺，防纠葛
  · 健康：注意肝胆/作息
  · 建议：善用人脉，稳中求进
```

#### Layer 4：专业层 — 体用合一

目的：深入命盘内在结构

```
来因宫：夫妻宫（甲戌）七杀+文曲
→ 人生主线在合作关系

体用分析：
  体=命宫（紫微平）→ 本质稳重但需激发
  用=官禄宫（廉贞禄+天府）→ 事业弹性与稳定并存
```

## 💞 合盘匹配引擎

### 5维度评分体系

合盘匹配不是玄学打分，而是基于紫微斗数理论的结构化分析。

#### 维度一：命宫互看

A的命宫星曜和B的命宫星曜之间是否存在良性互动：

| A命宫 | B命宫 | 关系 | 评分影响 |
|---|---|---|---|
| 紫微(平) | 武曲(旺)+天相(旺) | 紫微喜武曲天相辅佐 | +10分 |

#### 维度二：夫妻宫共振

| A夫妻宫 | B夫妻宫 | 关系 | 评分影响 |
|---|---|---|---|
| 七杀(得) | 天同(得) | 刚柔互济，互补性强 | +15分 |

#### 维度三：四化交集

同步化禄/化权/化科/化忌 → 缘分深度标记：

```
A四化：廉贞禄(官禄)  破军权(福德)  武曲科(财帛)  太阳忌(子女)
B四化：太阳禄(迁移)  武曲权(命宫)  太阴科(夫妻)  天同忌(福德)
→ 武曲和太阳同时被引动，轻度共鸣
评分影响：+5分
```

#### 维度四：五行互补

| A五行 | B五行 | 关系 | 评分影响 |
|---|---|---|---|
| 水二局 | 木三局 | 水生木→相生 | +10分 |
| 金四局 | 火六局 | 火克金→相克 | -5分 |

#### 维度五：福德宫精神

| A福德宫 | B福德宫 | 关系 | 评分影响 |
|---|---|---|---|
| 破军(权)+禄存+天马 | 天同(得) | 变革 x 安逸，需调和 | 0分 |

#### 评分公式

```python
def _compute_score(dimensions):
    score = 60  # 基础分
    if both_marriage_not_empty: score += 10
    if common_transformations: score += 10

## 💎 技术亮点

### 1. 宫序动态映射

iztro-py返回固定地支序（寅→丑），但紫微斗数标准序是**从命宫开始逆时针**。通过偏移量公式 `(soul_branch_index + i) % 12` 精确还原。此Bug修复耗时最长——初始版本硬编码映射表只对特定命宫位置正确。

### 2. 四层Prompt塔

3400+字结构化Prompt，覆盖四层分析+JSON输出模板。每层均告诉AI"你应该关注什么、输出什么格式"，而不是给一堆raw数据让它自由发挥。

### 3. 5维度合盘算法

| 维度 | 权重 | 计算方式 |
|---|---|---|
| 命宫互看 | ±20 | 星曜善恶互动 |
| 夫妻宫 | ±20 | 双方夫妻宫星曜组合 |
| 四化交集 | ±15 | 同步化曜的数量 |
| 五行互补 | ±15 | 生克关系 |
| 福德宫 | ±10 | 精神世界契合度 |

### 4. 全量6语国际化

宫位/星曜/四化/干支/UI标签全量翻译，采用嵌套Dict映射 + 单函数入口 `t(key, lang)`。新增语言只需往Dict加map。

### 5. 双轨排盘（Python + JS）

Telegram Bot用iztro-py（后端），Web前端用iztro（浏览器），两套引擎独立计算结果一致。Web端零后端依赖。

### 6. DeepSeek多模型适配

主力DeepSeek国内直连，Claude/GPT可插拔。DeepSeek特有的 `【】`→`<>` 括号适配自动处理。
